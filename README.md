## 🚀 Quick Start

```bash
# 1. Clone
git clone https://github.com/ErkinovAsliddin/bazmfixed.git
cd bazmfixed

# 2. Install
npm install            # or: pip install -r requirements.txt

# 3. Configure
cp .env.example .env

# 4. Run
npm run dev            # or: python app.py
```

Open **http://localhost:3000**.

> ⚠️ Never commit your `.env` file or any secrets.
